## Project Overview

A full-stack Cafe / Restaurant Online Ordering System was developed to allow customers to browse menu items, manage a shopping cart, place orders, and track order status. An administrative dashboard enables staff to view and manage customer orders.

---

## Technology Stack

- Next.js
- TypeScript
- Prisma ORM
- SQLite Database
- Zod Validation
- HTML
- CSS
- Git & GitHub

---

## Features Implemented

### Customer Features

- Browse menu
- View product details
- Add items to cart
- Update cart quantity
- Remove items from cart
- Checkout
- Order confirmation
- Order tracking

### Admin Features

- View customer orders
- Update order status
